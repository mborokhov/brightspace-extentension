Due North

Connect Google Calendar

This optional feature needs a one-time Google Cloud setup. Brightspace, Gradescope, and MyLab still work without an API key.

  1. Use Google Chrome. Open chrome://extensions, enable Developer mode, and copy Due North’s ID. This installation: shown in Chrome after installation.
  2. In the Google Cloud console, create or select a project and enable Google Calendar API.
  3. Under Google Auth Platform, configure Branding, Audience, and Data Access. For a personal test, choose External, keep Testing, and add your Google account as a test user. Add only this scope: https://www.googleapis.com/auth/calendar.app.created.
  4. Under Clients, create an OAuth client with application type Chrome Extension. Enter the exact Due North extension ID from step 1. Copy the client ID ending in .apps.googleusercontent.com. No client secret is needed.
  5. In Due North’s extension/manifest.json, add the following top-level property, replacing the client ID. Keep the rest of the file and any existing key unchanged. Alternatively, from the due-north folder run node scripts/configure-google.cjs --client-id YOUR_CLIENT_ID.
"oauth2": {
  "client_id": "YOUR_CLIENT_ID.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/calendar.app.created"]
}

JSON properties need a comma between them. Reload Due North in chrome://extensions, then open Calendar → Connect calendar and approve Google’s permission prompt.

On your iPhone

Open Google Calendar, sign in to the same account, make the Due North — Assignments calendar visible, and allow notifications in iPhone Settings and the Google Calendar app. Reminders already synced to Google work while your computer is off. Changes need Chrome online before they can reach Google.

Sharing the extension

An OAuth client is tied to an extension ID. Unpacked copies in different folders or profiles may have different IDs, so friends may need their own client. For a single shared setup, publish through the Chrome Web Store using a stable extension ID and complete Google’s production consent requirements. Do not add or change a manifest key on an existing installation: changing its ID can make its saved data inaccessible.

What sync does

This is one-way sync into a separate calendar. Date edits update existing events. Completing, deleting, merging, or excluding assignments removes obsolete events and future reminders. Unchecking restores an event. Date-only deadlines have no reminder; inferred-year and undated tasks stay local until corrected. Google changes do not update Due North.

If you previously imported an .ics file, remove those imported copies yourself; this connection cannot identify or manage them. Do not import .ics snapshots into the connected calendar.

If setup fails

Check the client’s extension ID, enabled Calendar API, test-user account, scope, and Chrome profile sign-in. Google test-mode authorization can expire; use Reconnect when prompted. School-managed accounts may block access. Due North never opens Google sign-in without a Connect or Reconnect click.

If calendar creation is interrupted, check Google Calendar for an empty Due North calendar before pressing Retry setup. An uncertain creation is never automatically repeated. Disconnect removes this installation’s events; it leaves the calendar and your other events intact. Keep Chrome online until removal finishes before clearing local data or uninstalling.
