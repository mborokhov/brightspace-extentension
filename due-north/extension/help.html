Setup & help

Install or update

Open chrome://extensions or edge://extensions, enable Developer mode, and choose Load unpacked. Select the extension folder containing manifest.json. Seeing only the icons subfolder in this picker is normal. For an existing installation, click Reload. Reload your school tabs too.

Sync your courses

  1. Sign in to Brightspace and Gradescope. Open your current course lists. In Brightspace, visit both Assignments and Quizzes.
  2. Open Courses here. Current-semester labels are recognized automatically. Confirm any unlabelled current courses once. Older courses are excluded.
  3. For MyLab Math, click its source button, allow optional site access, and reload your Homework and Tests page. Confirm the course if its semester is unlabelled.
  4. Click Sync. Use Sync details to check coverage. Expand sections and visit additional list pages yourself when needed.

Dates and completion

Edit date changes a deadline locally and survives future syncs. Use source date restores the latest original deadline. The weekly chart counts incomplete assignments; click a bar to filter the list. The Calendar view supports monthly browsing and editing.

Gradescope uses the right-hand due date. Brightspace uses the Due on line below the name. A populated quiz Evaluation Status means completed. Your completion checkbox overrides source status locally; Use source status resets it. Nothing is submitted or changed on school sites.

Calendar and reminders

Export .ics saves a calendar snapshot for import. Google Calendar live sync is not connected. In Settings, match your course time zone and optionally enable reminders. Reminders require a running browser, readable times, and recently synced records.

Share and privacy

Share the original project ZIP or repository. Each person uses their own browser profile and school login. No API key or programming tools are needed. Assignment data stays in local browser storage. Settings can pause collection or clear it. Use separate browser profiles for different school accounts.

Coverage

Only loaded, supported lists can be collected. Syllabus PDFs, announcements, and unsupported layouts are not read. The included tests use synthetic pages; MyLab Math's signed-in layout still needs live verification. Missing deadlines can be entered with Edit date.
