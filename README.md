# Due North

Purdue assignment tracker for Brightspace, Gradescope, and MyLab Math. No API key required.

**Install:** download/extract this repository, then load the **due-north/extension** folder from Chrome or Edge's Extensions page with Developer mode enabled. Select the folder, not the manifest file.

See [setup and usage](due-north/README.md), [privacy](due-north/PRIVACY.md), and [validation](due-north/TESTING.md).

Version 0.7.1 includes an Apple-style design across the dashboard, calendar, popup, and dialogs, a toolbar quick view, manual assignments, and reversible cross-platform merging. It retains editable deadlines, weekly workload, the calendar, current-semester filtering, quiet syncing, and optional MyLab Math collection. Optional Google Calendar sync updates edited deadlines, removes completed events and future reminders, and supports iPhone reminders after syncing. It requires Chrome and the [one-time Google setup](due-north/extension/google-setup.html). School syncing still needs no API key; signed-in integrations need live verification.

Click the extension icon for upcoming deadlines, completion, and Sync. Choose Open planner for the dashboard, or Add for its manual assignment editor. Merge duplicate copies from an assignment's Details menu; both source links remain available.

v0.7.1 adds bar-only hover styling, a clear selected-day label and filter strip, visible deadline years, and repairs for cached year inference using the course semester. Reload the existing unpacked extension to apply the update.
