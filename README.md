# Due North

Purdue assignment tracker for Brightspace, Gradescope, and MyLab Math. No API key required.

**Install:** download/extract this repository, then load the **due-north/extension** folder from Chrome or Edge's Extensions page with Developer mode enabled. Select the folder, not the manifest file.

See [setup and usage](due-north/README.md), [privacy](due-north/PRIVACY.md), and [validation](due-north/TESTING.md).

Version 0.6.0 includes an Apple-style design across the dashboard, calendar, popup, and dialogs, a toolbar quick view, manual assignments, and reversible cross-platform merging. It retains editable deadlines, weekly workload, the calendar, current-semester filtering, quiet syncing, and optional MyLab Math collection. Google Calendar live sync is not connected; signed-in site layouts still need live verification.

Click the extension icon for upcoming deadlines, completion, and Sync. Choose Open planner for the dashboard, or Add for its manual assignment editor. Merge duplicate copies from an assignment's Details menu; both source links remain available.
